## Scientific interpretation

- Examine both coverage and recall; no communication advantage by itself establishes operational utility.
- Different privacy spending is an operating-point trade-off, not a privacy-controlled superiority claim.
- A release threshold changes scheduling behavior; it is not a specified coverage guarantee.
- Packet-content DP does not imply secrecy of transmission metadata or timing.
- The source version and original v1.9 versus public-score variant must be identified consistently.
- If the original source still uses raw attribution residuals for PRISM scheduling, it is NOT a public-state scheduler.
