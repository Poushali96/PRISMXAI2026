# PRISM-XAI — ICC 2027 reproducibility repository

**PRISM-XAI: Privacy-Accounted Semantic Explanation Scheduling for Smart-Grid Edge Intelligence**

This repository package was assembled from the latest uploaded v19 manuscript package,
the latest Colab notebook, and the recovered clean experiment-results archive generated by the notebook.

## Repository layout

- `code/`
  - `prism_xai_icc2027_v1_9_selective_release.py` — current v19 experiment engine.
  - `prism_xai_icc2027_v1_8_matched_fallback.py` — previous matched-fallback engine retained for provenance.
- `notebooks/`
  - `run_prism_xai_v18_matched_fallback_colab.ipynb` — Colab development/reproduction notebook containing the v18 and v19 run cells.
- `paper/latest_v19_uploaded/`
  - exact extracted contents of the latest manuscript archive supplied for this repository build.
- `results/current_v19/`
  - current M8 main results, M4 sensitivity, verification, and feasibility-ladder diagnostics.
- `results/legacy_v18/`
  - older v18 sensitivity outputs retained separately so they cannot be confused with the current evidence.
- `REPRODUCIBILITY.md`
  - commands for the v19 M8/M4/verification experiments.
- `requirements.txt`
  - Python dependencies used by the experiment scripts.
- `provenance/`
  - hashes and file manifest for auditability.

## Current manuscript evidence

The v19 main experiment is the M8 selective-release operating point with:
- two real load datasets (OPSD and UCI),
- two XAI implementations,
- privacy budgets 8, 16, and 32,
- six schedulers,
- ten paired random seeds,
- 720 total main runs.

The repository deliberately preserves the distinction between:
1. the current v19 main evidence,
2. v19 sensitivity/diagnostic studies, and
3. legacy v18 experiments.

## Data

Raw public dataset caches are not included. This is intentional: the experiment scripts download
the public datasets and the result directories contain provenance/configuration records.

## Paper package note

The folder `paper/latest_v19_uploaded/` is the exact extracted content of the manuscript archive provided
for this build. Its internal `README_FIRST.md` is preserved unchanged. If that internal README names a
supplement artifact that is not present in the uploaded archive, the repository does not fabricate it;
only files actually present in the supplied archive are included.
