# PRISM-XAI ICC 2027 v19 final reader-report package

## What changed in this revision

The six-page paper remains the submission-facing manuscript, but it now contains an explicit paragraph stating that an extended reader-facing supplementary report with the full v19 evidence and result-by-result discussion can be provided by the authors upon request.

The supplementary document has been completely rewritten as a technical report rather than a plot/table archive. It now tells the empirical story in a reviewer-readable order: integrity checks; communication and energy; coverage/recall/precision; explanation fidelity; latency/AoX/fairness; privacy accounting and attack AUC; OPSD versus UCI; epsilon sensitivity; XAI-method sensitivity; MAP-XAI-only versus full PRISM; external-baseline interpretation; paired statistics; temporal traces; M4 versus M8; the full feasibility ladder; the privacy-release frontier; metric-by-metric macro tables; limitations; and consolidated design implications.

All available v19 result PNG figures in the supplement figure bundle are included and discussed. All available supplement table files are also included and referenced. The exhaustive 72 condition means, 60 paired comparisons, and 50 privacy-release-sweep means appear as numerical appendices after the readable report narrative.
